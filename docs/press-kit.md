## 2. Key Factual Talking Points

- **Sub-Second Performance:** Cold launch time of ~470ms; temporary file scan time of ~420ms.
- **Ultra-Lightweight Footprint:** Combined RAM working set of ~42 MB; uses 0.0% CPU when closed.
- **Quarantine Safety Net:** Files marked for removal are staged into an isolated vault for 14 days, allowing byte-for-byte restoration.
- **No Registry Scareware:** Adheres strictly to Microsoft best practices by avoiding speculative registry deletion.
- **Privacy by Default:** Browser cache cleanup preserves saved passwords, login sessions, and cookies.
- **Dual Distribution:** Packaged as both a single-click consumer setup (`.exe`) and an enterprise WiX MSI (`.msi`).
