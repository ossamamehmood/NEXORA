## What's New in NEXORA v1.0.0-rc.1

We are proud to introduce the first Release Candidate of **NEXORA** — a PC Cleaner, Privacy Manager & System Maintenance Suite designed with safety, transparency, and user control at its core.

### Highlights
- **Native Rust Engine:** Sub-second scans (~19,000 files/sec), ultra-low memory footprint (~42 MB RAM), and zero background surveillance services.
- **8-Stage Cleaning Lifecycle:** Scan -> Review -> Select -> Preview -> Confirm -> Clean -> Verify -> Recover. Complete transparency with dry-run confirmations.
- **Quarantine Vault:** Files marked for removal are staged in an isolated vault by default, allowing 1-click byte-for-byte restoration.
- **Zero Scare Tactics:** Honest diagnostic findings with no synthetic error counts or high-pressure upselling.
- **Privacy Center:** Web cache and history cleanup for Chrome, Edge, Firefox, and Brave with strict preservation of passwords and login sessions.
- **Startup Manager:** Toggle Windows background startup entries (`HKCU\Run` & `HKLM\Run`) safely using Windows registry APIs.
- **Duplicate Finder:** Cryptographic SHA-256 duplicate file detection guarantees zero false positives.
- **Windows Maintenance Center:** Actionable routines including DNS cache flush, DISM component store cleanup, and Windows Update cache reset.
- **In-App Beta & Telemetry Vault:** Transparent user feedback system allowing optional, sanitized diagnostic sharing with full JSON preview before submission.
- **Dual Packaging:** Available as a single-click consumer NSIS installer (`.exe`) and an enterprise WiX MSI package (`.msi`).
