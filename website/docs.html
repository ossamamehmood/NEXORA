Getting Started with NEXORA

NEXORA installs in seconds into user-space. Once launched:

  1. Review the Overview Dashboard to inspect your live CPU, RAM, and volume capacity.
  2. Navigate to Smart Cleaner and click Scan Candidates.
  3. Inspect the categorized candidate files. Click Preview Cleanup to verify paths.
  4. Click Execute Safe Clean. Reclaimable space is freed, and files are safely quarantined.

Troubleshooting: Skipped Files

If Smart Cleaner reports that files were skipped, an active Windows application currently holds an exclusive lock on those cache files. Close active applications and re-run Smart Cleaner to complete the clean.
