The Complete NEXORA Feature Suite

14 native utilities written in Rust and Windows API for maximum transparency, deterministic performance, and zero background battery drain.

⚡

Smart Cleaner

Targets approved temporary directories (%TEMP%, C:\Windows\Temp), crash dumps, and Windows Error Reporting logs. Features dry-run confirmation before any disk changes.

🔍

Deep Cleaner

Advanced category filters for developers and power users: purge stale npm cache, pip wheel cache, cargo build artifacts, and system diagnostics with risk stratification.

🛡️

Privacy Center

Cleans temporary web caches, URL history, and script bundles across Chrome, Edge, Firefox, and Brave. Saved credentials and active sessions are strictly preserved.

🎮

Reversible Gaming Mode

Elevates active game thread priority to High or AboveNormal and activates the native Windows High Performance power scheme. Zero risky registry hacks, 100% reversible via an on-disk journal.

📊

System Monitor

Real-time hardware telemetry and process inspector. Features a protected process shield that blocks accidental termination of core Windows services like csrss.exe, lsass.exe, and explorer.exe.

🚀

Startup Manager

Inspects and toggles background applications launched at Windows boot. Uses native Windows registry APIs (StartupApproved\Run) without modifying critical startup manifests.

📂

Disk Analyzer

Interactive visual folder traversal with proportional size allocation bars and automatic identification of the top space-consuming files across any drive partition.

♊

Duplicate Finder

Find redundant files across storage volumes using multi-stage size filters followed by full SHA-256 cryptographic verification. Zero false positives guaranteed.

📦

Application Manager

Reads installed programs directly from Windows Uninstall registry hives (HKLM, HKCU, WOW6432Node), displaying publisher, version, and estimated size.

🩺

System Diagnostics

Inspects primary volume storage capacity, physical RAM pressure, OS kernel services, and network socket / DNS protocol stack health.

🔧

Maintenance Center

Actionable Windows maintenance tasks: DNS resolver cache flush (ipconfig /flushdns), DISM Component Store cleanup, and Windows Update cache reset.

🗄️

Quarantine Vault

Files marked for cleanup are staged into an on-device vault by default. Restore any file with a single click — byte-for-byte identical rollback.

📜

Activity History

Comprehensive local SQLite audit log documenting every scan timestamp, reclaimed byte count, quarantined item, and system action.

💬

Beta Feedback Vault

Direct in-app communication channel with the engineering team. Allows optional, sanitized diagnostic log sharing with raw JSON preview before submission.
