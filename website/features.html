Modular Power

NEXORA Feature Suite

13 unified utilities engineered in native Rust for maximum transparency and zero background system overhead.

⚡

Smart Cleaner

Targets approved temporary directories (%TEMP%, C:\Windows\Temp), crash dump dumps, and Windows Error Reporting logs. Features a dry-run confirmation preview before any disk changes.

🔍

Deep Cleaner

Advanced category filters designed for developers and power users: purge stale npm cache, pip wheel cache, cargo build artifacts, and system diagnostics with risk stratification.

🛡️

Privacy Center

Cleans temporary web caches, URL history, and temporary script bundles across Google Chrome, Microsoft Edge, Mozilla Firefox, and Brave. Saved credentials and active sessions are strictly preserved.

📊

System Monitor

Real-time hardware telemetry and process inspector. Features a protected process shield that blocks accidental termination of core Windows services like csrss.exe, lsass.exe, and explorer.exe.

🚀

Startup Manager

Inspects and toggles background applications launched at Windows boot. Uses native Windows registry APIs (StartupApproved\Run) without modifying critical startup manifests.

📂

Disk Analyzer

Interactive visual folder traversal with proportional size allocation bars and automatic identification of the top 10 largest space-consuming files.

♊

Duplicate Finder

Find redundant files across storage volumes using multi-stage size filters followed by full SHA-256 cryptographic verification. Zero false positives guaranteed.

📦

Application Manager

Reads installed programs directly from Windows Uninstall registry hives (HKLM, HKCU, WOW6432Node), displaying publisher, version, and estimated size.

🩺

System Diagnostics

Inspects primary volume storage capacity, physical RAM pressure, OS kernel services, and network socket / DNS protocol stack health.

🔧

Maintenance Center

Actionable Windows maintenance tasks: DNS resolver cache flush (ipconfig /flushdns), DISM Component Store cleanup, and Windows Update cache reset.

🗄️

Quarantine Vault

Files marked for cleanup are staged into an on-device vault by default. Restore any file with a single click — byte-for-byte identical rollback.

💬

Beta & Telemetry Vault

In-app communication channel with the engineering team. Allows optional, sanitized diagnostic log sharing with raw JSON preview before submission.

🎮

Reversible Gaming Mode

Elevates active game thread priority to High or AboveNormal and applies the native Windows High Performance power scheme. Zero risky registry hacks, 100% reversible with an on-disk crash recovery journal.
