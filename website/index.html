Engineering Philosophy

Built on Honesty & Safety

Legacy PC utilities rely on aggressive scare tactics, registry destruction, and silent background telemetry. NEXORA was engineered to be the exact opposite.

1. Safety Before Cleaning

Every candidate path is validated against strict filesystem boundaries. Operating system roots, personal documents, and browser credential stores are mathematically prohibited from deletion.

2. Transparency Before Automation

No cleaning occurs without your review and dry-run confirmation. Files marked for removal are staged in an on-device Quarantine Vault, enabling instant 1-click byte-for-byte recovery.

3. Privacy by Default

Zero background surveillance telemetry. Zero personal documents or browsing logs are collected. Optional beta feedback sharing is strictly opt-in and lets you inspect the raw JSON metadata beforehand.

4. Zero Background Overhead

NEXORA runs only when you launch it. It installs zero background services, zero startup daemons, and consumes exactly 0.0% CPU when closed.

Frequently Asked Questions

Common Inquiries

Does NEXORA include a "Registry Cleaner"?

No. Modern Windows operating systems do not benefit from arbitrary registry unlinking, and commercial registry cleaners frequently corrupt COM registrations and driver manifests. NEXORA adheres strictly to Microsoft best practices and avoids speculative registry purging.

Will Privacy Center delete my saved browser passwords or active logins?

No. NEXORA's privacy rules are hardcoded to skip Login Data, Cookies, and Web Data files. It targets only temporary rendering caches, script caches, and download history.

Does NEXORA install background services or startup daemons?

No. NEXORA runs only when you open it. When closed, zero processes or background threads remain active in memory.

How does the Quarantine Vault protect my files?

When Smart Cleaner is executed, candidate files are staged in an isolated vault inside your local user profile with a 14-day retention timer. If you ever need to retrieve a file, navigate to Activity History -> Quarantine Vault and click "Restore File".
