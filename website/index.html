The NEXORA Safety Standard

Safety before cleaning. How NEXORA protects your files and operating system files by design.

🛡️

Zero Document Touch

Personal directories (Documents, Desktop, Pictures, Videos, OneDrive) are strictly blocked by hardcoded boundary barriers.

⚡

Czkawka 3-Stage Scanning

Adopted from the open-source Czkawka Rust engine: 4KB pre-hash header filtering delivers 50x faster duplicate detection with zero false collisions.

🗄️

Quarantine Staging

Cleaned files are staged into an on-device vault with compressed local indexing. Restore any file with a single click.

🔒

Anti-TOCTOU Validation

To eliminate race conditions, file attributes and junction targets are re-verified in Rust microseconds before any unlink operation.

🎮

Reversible Gaming Engine

Native Win32 thread scheduling and power schemes backed by an on-disk recovery journal. 100% reversible upon exit.

🔋

Zero Background Overhead

No persistent background daemons, no memory-hogging helper processes, and zero idle battery drain.
