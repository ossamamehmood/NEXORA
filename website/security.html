Built on the principle of Absolute System Safety.

Traditional PC utilities often do more damage than good by blindly deleting files and hacking into critical registry hives. NEXORA was engineered to put an end to that paradigm.

1. Immutable Whitelist & Blacklist Enforcement

The native Rust security engine strictly blocks operations targeting C:\Windows\System32, Boot, Program Files, user Documents, Desktop, Pictures, and sensitive credential databases. Any path traversal attack (e.g. ..\..) is rejected instantly.

2. Zero Registry Deep Cleaning in v1.0

Microsoft officially advises against automated registry cleaners because deleting orphan keys provides zero measurable performance gain while introducing immense stability hazards. NEXORA strictly excludes arbitrary registry wipeouts.

3. Quarantine Staging Vault (14-Day Rollback)

Eligible cache removals are staged in an encrypted local quarantine directory with full metadata recorded in SQLite. If any application requires a removed cache file, it can be restored with a single click.

4. Sandboxed Least-Privilege IPC

Frontend TypeScript code has zero direct filesystem access. All commands pass through Tauri 2's strictly scoped IPC boundary and are re-validated in memory by the Rust kernel immediately prior to execution.
